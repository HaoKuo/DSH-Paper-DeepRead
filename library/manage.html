需要启用管理服务的站点。 当前页面不是由 deploy/serve.py（或 DSH-Paper-DeepRead 插件）提供，只能用只读方式打开文献库； 上传与报告管理功能不可用。请通过站点地址打开本页，例如 http://<host>:8080/manage.html。
  1. 把 PDF 拖进下方收件箱（开放上传，不离开本页）。
  2. 上传后自动进入精读队列，本机 deepread worker 会用 headless Agent 完成精读并把报告写回文献库。
  3. 报告完成后自动重建索引并发布，文献库首页与 DSH 插件同时可见；失败会显示原因并可重试。

上传令牌

站点启用了上传令牌（KB_UPLOAD_TOKEN）：上传请求需要附带 X-KB-Upload-Token 请求头。 令牌只保存在本标签页的 sessionStorage，不会写入站点。

精读队列（自动处理）

还没有上传记录。

「删除」只移除队列记录与收件箱 PDF，不会删除已生成报告；删除报告请到「报告管理」。需要先解锁管理令牌。

自动精读（本机 worker）

上传后自动进入精读队列（本机 worker 处理，无需手动复制指令；失败会显示原因并可重试）。 worker 会用 paper-deepread-html 技能完成精读、校验报告，然后自动重建索引并发布。

手动交给 Agent（备用）

自动 worker 未运行或不可用时，可把下面这段指令（含服务器上的 PDF 绝对路径）复制给任意 Agent。

提示：worker 状态可在队列里看到；「报告管理」页可继续隐藏/删除报告或手动重新发布。

管理权限

写操作（隐藏/删除/重建发布/删除上传）需要管理令牌。令牌只保存在本标签页的 sessionStorage，不会随页面发布。

尚未解锁：可以浏览，但写操作会返回 401。请向站点维护者索取管理员令牌。

发布与恢复

      
「重建索引并发布」先用 build_library.py 重新生成 index.html/index.md，再运行
        deploy/publish.sh 生成新的 site/releases/<ts> 并切换 site/current。
        发布是原子的，旧版本保留最近 5 个，可回滚：把 site/current 指回旧 release 即可。

      

        
        删除的论文在 <library>/.trash/ 下，按时间前缀命名。
