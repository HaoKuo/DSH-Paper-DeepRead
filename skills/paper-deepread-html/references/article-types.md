# 文章类型 → 解读重点（Article Types）

精读的第一步不是打开图，而是判断**这是一篇什么文章**。同一套模板套在所有论文上，最常见的后果是：
拿研究论文的尺子量综述（追问 n、对照、P 值），或拿综述的尺子量研究论文（只总结观点、不看证据）。

## 一、先判类型

| 类型 | 判定线索 | 核心问题 |
|---|---|---|
| **Research article**（原始研究） | 有新的实验/样本/数据/benchmark；有 Methods、Results、统计检验、对照 | 它做了什么新证据？证据够不够支撑结论？ |
| **Review**（综述） | 没有新实验；以已发表文献为材料；常带 taxonomy、timeline、comparison table、decision tree | 它如何组织一个领域？覆盖是否完整、比较是否公平？ |
| **Methods / protocol**（方法论文） | 新方法/流程，通常有 benchmark 与对照，但重点在可复现性 | 方法是否可复现？相对现有方法强在哪、代价是什么？ |
| **Perspective / commentary**（观点） | 明确表达作者立场，证据以论证和先例为主 | 论点是什么？哪些是证据、哪些是判断？ |
| **Mixed**（混合） | 既有新数据，又有大范围综述框架（如方法论文带领域回顾） | 主体按 research 读，另加 review 式的覆盖与分类检查 |

判定后把 `article_type` 写进 `meta.json`（`review` / `research` / `methods` / `perspective` / `mixed`），
并在报告开头用一句话说明“本文是哪种文章，因此本章按什么标准读”。这一步不是形式，它决定后面所有
“证据强度”的判断口径。

**硬规则**
- 综述里的“430 倍”“88.7%”等数字是**转述的二手证据**，只能问“作者是否准确转述、是否给出处”，
  不能问“这个实验的 n 是多少”（除非原文同时给了原始研究细节）。
- 研究论文里的“领域共识”段落是**背景**，不是本文的数据；不要把 Introduction 的综述句当成结果。
- 混合型文章：数据部分按 research 查对照/统计，框架部分按 review 查覆盖/分类；不要用一方的标准放过另一方。

## 二、Review 的解读重点

### 1. 范围与检索（先看它怎么选文献）
- 有没有数据库、检索式、时间窗、纳入/排除标准、PRISMA 流程图？
- 是系统综述（systematic review）、叙述性综述（narrative review），还是专家观点？
- 有没有说明“为什么是这些方法/这些图/这些表”？是否只覆盖英文、只覆盖商业平台、只覆盖作者熟悉的体系？
- 搜索截止到什么时候？截止后出现的新方法是否被漏掉？

### 2. 组织框架（它用什么坐标切领域）
- 分类轴是什么（按机制、按步骤、按平台、按应用）？轴选得好不好？
- 类别是否**互斥**、是否**穷尽**？有没有方法同时属于两类、或落在类别之外？
- 分类是作者新提出的，还是领域已有共识？作者有没有把“自己的分类”写成“领域标准”？
- 每个类别是否有明确边界与代表方法，而不是“举例列表”？

### 3. 章节账本（每一节都要回答）
对每一个主章节（含 Box、Perspective 前的总结节），写 2–4 段：
1. **这一节回答什么问题**：它在整篇论证中承担哪一环？
2. **作者怎么论证**：用了哪些代表性研究/机制/数字？哪些是举例、哪些是归纳？
3. **这一节的结论是什么**：作者想让你接受哪句话？
4. **小结与可疑处**：哪一步是推断、哪一类证据被省略、哪个反例没有被讨论？

不要用图注替代章节总结。图是证据碎片，章节才是论证链。

### 4. 比较与数字（二手证据的公平性）
- 表格里的数字是否同口径：同样品、同靶标、同对照、同测序深度？
- 有没有把“相对富集倍数”“阳性细胞比例”“reads 占比”“检测限”混在一列比较？
- 表格的 yes/no 列是否被当成“性能排名”？列名是否定义了操作标准？
- 作者是否明确说“不可横向比较”？如果没有，报告里要替他说。

### 5. 决策指南 / 推荐
- 推荐是基于机制推理、专家经验，还是有对照实验/benchmark 支撑？
- 阈值（如“10 个靶标”）是数据驱动还是经验值？作者有没有承认其任意性？
- 推荐是否依赖平台/预算/样本类型？换一个实验室还成立吗？
- 有没有“作者不推荐”的方法被草率排除？理由是否同维度？

### 6. 共识、争议与空白
- 哪些是领域已定论（consensus）、哪些仍有争议（controversy）、哪些是作者判断（opinion）？
- 作者有没有指出“缺少横向 benchmark”“缺少某种样本/平台”的空白？
- 这些空白是领域真空白，还是作者搜索范围的空白？

### 7. 综述的“时间性”
- 引用是否偏旧？是否覆盖近 2–3 年的预印本/新平台？
- 作者对未来的判断（如“长读长会取代 3′/5′”）是预测还是事实？证据是什么？
- 报告里要区分“截至搜索截止日的状态”与“作者对未来的押注”。

## 三、Research 的解读重点

### 1. 问题与新颖性
- 一句话：作者声称的第一个新东西是什么？相对哪篇前作？
- 这个缺口是真实的，还是作者把“没做过”包装成“很重要”？

### 2. 设计与对照
- 阴性/阳性对照、载体/空载、mock、批次、操作者、位置效应是否交代？
- n 是生物学重复还是技术重复？随机化/盲法？样本量/功效分析？
- 有没有把“技术重复的误差棒”当成“生物学重复”？

### 3. 方法可复现性
- 关键参数、试剂/仪器型号、软件版本、代码/数据是否可得？
- 统计检验与数据分布是否匹配？多重比较是否校正？效应量与 CI 是否给出？
- 失败样本/排除标准是否说明？

### 4. 结果链（按图/实验组，不只按面板）
- 每一张主图在论证链里承担哪一环：发现 → 因果 → 机制 → 推广？
- 关键比较的效应量、对照、n、误差棒类型、P 值（或 CI）是什么？
- 哪个结果是“相关”，哪个才是“因果”？中间缺哪座桥？

### 5. 替代解释与边界
- 有没有未排除的混杂（批次、位置、密度、光照、温度、操作者）？
- 结论能否跨体系/跨规模？放大或换样本后哪条约束先变？
- 作者在 Discussion 里承认的局限，是否足以推翻主结论？

### 6. 覆盖完整性（Research 硬要求）
- **全部主图与主表必须逐张精读**（图卡/表卡），不得因"只选 3–8 张"跳过任何主图/主表；
- **Results 的每一个小节都要有独立正文段落**（2–4 段：本节目标 / 关键证据与数字 / 结论与论证链
  位置 / 可疑处），不得用 Abstract 或图注替代；
- 支撑主结论的关键补充图/表（统计检验、对照、阴性结果、额外验证）必须解读或至少在主图段落中引用；
- 报告中必须有「阅读覆盖清单」，主图/主表 100% 有精读位置，跳过项写具体理由。

## 四、写进 `content.html` 的模板

### Review：章节精读
```html
<section id="sec-sections">
<h2 id="sec-sections">章节精读：这篇综述如何搭建论证</h2>
<p>本文是 <b>review</b>，不是原始研究；因此本章按“范围—框架—逐节论证—共识/空白”来读，
不把二手数字当作本研究的 n 或 P 值。</p>

<h3>§1 偏倚清单：六个步骤、三类来源</h3>
<p><strong>这一节回答什么：</strong>…</p>
<p><strong>作者怎么论证：</strong>…关键例子/数字 <span class="ev" data-ev="p.3">原文 p.3</span>…</p>
<p><strong>小结与可疑处：</strong>… <span class="tag">[推断]</span>…</p>
</section>
```

要求：
- 每个主章节至少一个 `<h3>`，2–4 段，段首用“这一节回答什么 / 作者怎么论证 / 小结与可疑处”；
- 至少一处原文页码/图号，至少一处批判性观察；
- 章节顺序按原文，不按报告作者的兴趣重排；
- 最后加一节“论证骨架与覆盖边界”，总结全文如何从问题走到推荐。

### Research：结果链
```html
<h3>§3 结果链：从表型到机制</h3>
<p><strong>这一节证明什么：</strong>…</p>
<p><strong>关键对照与数字：</strong>…n=…，误差棒=…，P=… <span class="ev" data-ev="p.5 Fig.3b">原文 p.5</span>…</p>
<p><strong>替代解释与边界：</strong>…</p>
```

要求：
- **逐章节写**：原文每个小节（Introduction、Results 各小节、Discussion）都写 2–4 段，按小节顺序，
  不按图号流水账；
- 每组主图/实验至少一段，按“发现—对照—机制—推广”组织；
- 每个关键结论给出效应量/对照/n/统计，不只写“显著”；
- 单列“Methods 可复现性”段，列出影响复现的参数与缺口；
- 报告末尾必须有「阅读覆盖清单」，覆盖全部主图/主表与关键补充图/表。

## 五、常见错误

**综述**
- 把摘要复述一遍就当“章节总结”；
- 用研究论文的标准追问“n 是多少”，忽略它是二手证据；
- 把作者的分类当成领域共识，不检查互斥/穷尽；
- 只读图，不读每节的首段/末段，错过作者的论证转折；
- 不检查覆盖偏差（只覆盖商业平台、只覆盖英文、只到某年）。

**研究论文**
- 把 Abstract 的结论当结果，不回到图和统计；
- 只看 P 值，不看效应量与对照；
- 把技术重复当生物学重复；
- 把“相关”写成“导致”；
- 不区分作者的解释与数据本身。

## 六、报告自检（加到 QA 前）

- [ ] `meta.json` 有 `article_type`，报告开头说明了类型与解读口径。
- [ ] Review：每个主章节都有 `<h3>` + 2–4 段 + 小结；至少 3 处“覆盖/分类/比较公平性”的批判。
- [ ] Review：至少 1 处指出“二手数字不可横向比较”或“分类不互斥/不穷尽”。
- [ ] Research：每个主结果都有对照、n、效应量/统计；至少 1 处替代解释。
- [ ] Research：**全部主图/主表都有图卡/表卡**，Results 每个小节都有 2–4 段正文，覆盖清单与正文一致。
- [ ] 两种类型都没有把“作者的话”写成“事实”，推断均有 `[推断]`。
