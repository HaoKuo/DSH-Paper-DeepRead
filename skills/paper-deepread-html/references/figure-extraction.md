# 图表裁切：原理、验收与修复

## 为什么不用"提取内嵌图片"

PDF 里的图通常有两种来源：

- **位图**：整张图是一张图片（照片、拼合图）。直接抽内嵌图片会丢掉面板字母、轴标签（它们在 PDF 文字层里）。
- **矢量图**：matplotlib/R/Illustrator 导出，由成千上万条线段、文字构成，没有"一张图"可抽。

因此正确做法是 **按页面坐标裁切渲染**：先定位"图区矩形"，再用 `page.get_pixmap(clip=rect, dpi=220)`
把该矩形渲染成像素图。这样面板字母、轴刻度、图例都保留，分辨率也可控。

## 检测流程（paper_ingest.py 做的事）

1. **图注锚点**：在文字块里找 `Fig. 1 |`、`Figure 1.`、`FIG. 1:`、`Extended Data Fig. 1`、
   `Supplementary Fig. S1`、`Table 1` 等；图注块可能跨多行，取整块并合并紧跟其后的续行。
2. **图区候选**：把该页的
   - 内嵌图片框（`page.get_image_info()`）
   - 矢量绘图框（`page.get_drawings()` 的 rect）
   去噪（整页背景、页眉页脚横线、1–2 pt 的发丝线），按垂直间隙聚类。
3. **选簇**：取与图注同一栏（双栏论文要先从文字块 x0 分布推断栏带）、且紧邻图注（图注在图下方时取
   上方的簇；表格图注通常在上方，取下方的簇）的那个簇；多栏宽图可跨栏。
4. **渲染裁切**：四周留 4–6 pt 边距，clamp 到页面内；默认 220 dpi，长边不超过 1600 px；输出
   `assets/figN.png`（表格为 `tabN.png`）。
5. **调试图**：`debug/figN-overlay.png` 在整页渲染上画出图区（红框）和图注（蓝框）；
   `debug/contact-sheet.png` 把所有裁切换成缩略图墙 —— **这两张图是验收入口**。

## 验收（必须看图）

用 `read_image` 打开 `debug/contact-sheet.png`，逐张确认：

- [ ] 只有图本身 + 面板字母（a/b/c）+ 轴标签/图例；
- [ ] 没有正文段落、页眉页脚、相邻图注混入；
- [ ] 没有切掉坐标轴、图例、面板字母、比例尺；
- [ ] 图注没有被包含进来（除非显式 `--with-caption`）；
- [ ] 表格：表头与脚注完整，列不被截断。

发现不对时，打开对应 `debug/figN-overlay.png` 读坐标（PDF point，原点左上），用
`--bbox "fig2=x0,y0,x1,y1"` 重跑。坐标可以先用 overlay 目测，再迭代 1–2 次。

## 常见问题与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 裁切带进整段正文 | 图区上边界被文本块污染 / 簇合并过头 | overlay 读图顶边，手动上移 `y0` |
| 切掉上面板 a | 图区起点太高 / 面板字母在文字层外 | 手动 `y0` 减小 8–15 pt |
| 双栏论文只切到左栏 | 栏带推断失败或图跨栏 | 手动把 `x0/x1` 扩到整幅；或 `--bbox` 全宽 |
| 矢量图只切到一小块 | 矢量元素散落、聚类断开 | 用 caption 上沿与上一段正文下沿做上下界，`--bbox` 全宽 |
| 图注在上一页 / 跨页图 | 图与图注不同页 | 取图所在页；报告里注明"图注见 p.N" |
| 表格被当成图 | 检测把表格结构当图区 | `--only` 排除，或改用 `tables.md` 的文字 |
| 裁切含白色大片留白 | 图区含了图外的空白 | 可接受；如需收紧，手动缩 bbox |
| 图片太糊 | dpi 不够 / 原图本身低清 | `--dpi 300`；原图低清就保持，别用 AI 放大冒充 |

## 分辨率与体积

- 屏幕阅读：长边 1400–1600 px、220 dpi 足够（Retina 上 2× 也清晰）。
- 单文件内嵌 base64 会膨胀 ~33%：5 张 1500 px 图 ≈ 5 MB 报告，属正常。
- 超过 25 MB 时：`--dpi 180 --max-width 1200` 重裁，或 build 用 `--no-inline` 交付 assets 目录。
- 不要用 JPEG 存折线图/文字（会出现彩色振铃）；照片类裁切也建议保持 PNG。

## 关于"原图"的红线

裁切图必须来自 PDF 页面渲染，**不得**用 AI 生成、超分、重画来"修复"低清图。若原图确实模糊，
在报告里如实呈现并注明；重绘只能放在明确标注「AI 重绘示意图」的 SVG 里。

## 实测覆盖（paper_ingest.py v1，2026-10）

| PDF | 页数 | 检出 | 正确率 | 备注 |
|---|---|---|---|---|
| Nat Commun 2025（双栏、跨栏大图） | 13 | 5 图 | 5/5 | 图注跨栏合并正确，无 warning |
| Nature（48 pp，含 12 张 Extended Data） | 48 | 18 图 | 18/18 | 单页栅格图 |
| PLOS ONE（单栏） | 9 | 5 图 + 1 表 | 6/6 | 表格转 markdown；跳过 SI 文件清单式图注 |
| 合成压力集（矢量图/表上图注/整幅跨栏/同栏两图/噪声背景/并排两图） | 6 | — | 42/42 断言 | 构建时用合成 PDF 覆盖 |

实现要点（与本文开头一致，另有几条工程细节）：

- `debug/figN-overlay.png` 与 `debug/contact-sheet.png` **默认就写**；`--debug` 额外输出逐图注打分与
  `debug/detect.json`。`--no-crop` 时不生成裁切与调试图。
- `bbox` 字段 = 实际渲染裁切框（内容区 + 5 pt 内边距、clamp 到页面、已剪掉图注）；`--bbox` 视为精确裁切框，
  可重复，命中后 `detect:"manual"`。
- 图注在图上方（部分期刊/表格）、图注标签与正文分块排版的情况会自动判断方向；判断错时用 `--bbox`。
- SI 文件清单式图注（如 `Figure S1 … (TIFF)`）会被跳过，不生成垃圾裁切。
- 矢量图（matplotlib 等）没有内嵌图片，靠绘图指令框 + 图区文字标签一起聚类，可正确裁切。
- 正文被描边成矢量路径的 PDF 会污染聚类，运行会标 `detect:"manual"`，必须人工 `--bbox`。
- `--list` 仍需要 `--out`（约定签名），只打印不写文件。
