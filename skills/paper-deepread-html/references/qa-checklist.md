# 交付前 QA 清单

先跑 `scripts/qa_report.py`，再**用 `read_image` 亲自看截图**。机器检查通过 ≠ 看着没问题。

## 阻断级（必须修，否则不交付）

- [ ] 报告能从 `file://` 直接双击打开，无白屏、无 JS 报错。
- [ ] 所有原文图都能显示（qa.json `images.broken` 为空）。
- [ ] 裁切图内容正确：只有图 + 面板字母 + 轴标签，无正文混入，无切轴/切面板。
- [ ] 每张原文图都有：图号、页码、图注原文、`原文` 溯源行。
- [ ] 每张 SVG 重绘都有显式徽标（「AI 重绘示意图」/「数据转录自 Fig. X」）。
- [ ] 无外部资源引用（qa.json `externalResourceUrls` 为空；`<a href>` 超链接除外）。
- [ ] 1440 px 宽无横向滚动；390 px 宽无横向滚动（宽表用 `overflow-x:auto` 容器）。
- [ ] 数字/图号/页码与原文一致（抽查 5 处）。
- [ ] 无 `{{PLACEHOLDER}}` 残留。
- [ ] **目录、HTML、PDF 三者同名**，格式 `<发表年份>-<期刊名>-<文章名>`（例：
      `2025-Nature Communications-AI-driven high-throughput droplet screening of cell-free gene expression/`
      内含同名 `.html`、`.pdf`，以及 `RAW-<同名>.pdf`）。
- [ ] 原文 `RAW-*.pdf` 在同一目录；报告封面/溯源页与文献库卡片都有「查看原文」链接。
- [ ] 报告目录中**没有** `qa/`（QA 截图与逐页图只在临时目录，验收后删除）。

## 视觉级（应当修）

- [ ] 首屏（封面）在 1440 下不空洞：标题、一句话结论、关键指标、缩略图都在。
- [ ] 图卡：图片清晰（≥1200 px 宽裁切 220 dpi）、图注可读、面板解读层次分明。
- [ ] 深浅色模式下：正文对比度足够；图片在浅色卡片上（深色模式下不要透明贴底）。
- [ ] SVG：文字不溢出/不被裁切；箭头/连线对齐；步骤高亮状态明显。
- [ ] 目录 sticky 不遮挡内容；滚动高亮与当前位置一致。
- [ ] 灯箱：点图打开、滚轮缩放、拖拽、Esc 关闭；焦点返回触发元素。
- [ ] 打印预览（qa/report-print.pdf）：A4 分页合理，图不被拦腰截断，导航/灯箱不出现。
- [ ] 长表格/代码块不撑破版面。

## 内容级（交付前自审）

- [ ] 每节都有"证据 chip"，且 `data-ev` 与正文页码/图号一致。
- [ ] 至少 3 处具体批判（指向面板、对照、统计、n），不是泛泛而谈。
- [ ] 术语表覆盖关键缩写；首次出现给英文全称。
- [ ] 报告没有把"作者解释"写成"事实"；`[推断]` 标记齐全。
- [ ] 溯源页：PDF SHA-256、页数、裁切清单、生成日期齐全。

## 体积 / 兼容

- [ ] 单文件 < 25 MB（超出改用 `--no-inline` 或降 dpi）。
- [ ] 字体用系统栈（PingFang SC / Noto Sans SC / -apple-system），无网络字体。
- [ ] iPhone 宽度下封面、图卡、SVG 不破版。
